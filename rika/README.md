# 理科暗記ドリル（中学受験）

中学受験の理科のうち、暗記が中心の分野を練習するアプリです。ビルド不要で、`rika/index.html` をブラウザで開くだけで使えます。

## 収録内容（12単元・189問）
| 分野 | 単元 |
| --- | --- |
| 生物 | 植物のつくりとはたらき／花・種子・植物のなかま／季節と生き物／こん虫・動物／人体 |
| 地学 | 星と星座／月と太陽／天気と気象／流水・地層・火山 |
| 化学 | 気体の性質／水溶液の性質 |
| 実験器具 | ガスバーナー・てんびん・けんび鏡などの使い方 |

すべての問題に解説が付いています。

## 学習モード
- **4択テスト**：5／10／20問から選べます。まちがえると正解と解説が表示されます
- **一問一答カード**：答えを思い出してからカードをめくり、「できた／まだ」を自分でつけます
- **全問チャレンジ**：その単元の全問題
- **苦手だけ**：最後にまちがえた問題だけを出題（正解するとリストから外れます）
- **問題と答えを見る**：一覧で読んで覚える。「答えをかくす」で赤シートのように使えます
- **全分野ミックス**：ホームから全単元をまぜて出題

まだ覚えていない問題・まちがえた問題ほど出やすくなります。2回続けて正解すると「おぼえた」になります。
記録タブでは、最近2週間の解答数と単元ごとの正答率を確認できます。学習記録はブラウザ（localStorage）に保存されます。

PC ではキーボードでも操作できます（4択：`1`〜`4`、次へ：`Enter`、カード：`Space` でめくる・`1` できた・`2` まだ）。

## 問題の追加
`js/data.js` の `RAW_QUESTIONS` に `[問題文, 正解, [まちがい選択肢×3], 解説]` の形で追加します。
問題IDは単元内の順番で決まるため、記録がずれないよう各単元の末尾に追加してください。

## 構成
| ファイル | 内容 |
| --- | --- |
| `js/data.js` | 単元・問題データ |
| `js/app.js` | アプリ本体（出題・採点・記録） |
| `css/style.css` | スタイル |

## 印刷用プリント（PDF）
`print/` に分野別の A4 プリントがあります（表紙・単元ごとの問題ページ・解答解説ページ）。
問題データを変えたら、次のコマンドで作り直せます（Playwright と Chromium が必要）。

```sh
node rika/tools/make-print.js bio     # bio / earth / chem / lab
```
